# License decision required

Before publishing code publicly, choose and add a repository license.

Suggested default for a community Android application: **Apache License 2.0** (permissive, includes an explicit patent grant). This is a recommendation, not a legal determination.

Important:
- Model weights and model runtime may have separate licenses and terms.
- Knowledge packs, datasets, images, and documentation may have different licenses.
- A repository license does not automatically license third-party assets.
- Record attribution and license per pack/artifact.

Do not publish a blank or misleading license file. Add the official license text after the project owner confirms the choice.
